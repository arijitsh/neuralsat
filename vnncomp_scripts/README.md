# VNN-COMP Scripts & Diversity Evaluation

This directory contains utility scripts for evaluating NeuralSAT-Div's diversity sampling capabilities.

### `eval_diversity.py`
Evaluates the diversity of counterexamples generated by NeuralSAT-Div using HighDiv metrics (pairwise L2 distance and geometric coverage).
- **Triage Mode** (`--triage_only`): Scans a benchmark to rapidly identify `sat` instances.
- **Sampling Mode**: Executes stochastic DPLL search to collect `k` diverse witnesses.

**Example Usage:**
```bash
python vnncomp_scripts/eval_diversity.py \
  --benchmark_dir vnncomp2026_benchmarks/benchmarks/sat_relu/1.0 \
  --sat_instances_file sat_relu_dpll_instances.csv \
  --k 10 --timeout 120
```

### `scan_dpll.py`
Scans benchmark directories to systematically locate hard `sat` instances that strictly require DPLL branching to solve (i.e., where fast pre-attacks fail). Useful for constructing challenge sets for diversity sampling.

**Example Usage:**
```bash
python vnncomp_scripts/scan_dpll.py \
  --benchmarks_dir vnncomp2026_benchmarks/benchmarks
```
*(The scanner will output to `scan.out` in the current directory).*
